==================================================
FITUR APLIKASI

AUTH:

- login
- register
- logout
- JWT auth
- middleware role

ADMIN:

- CRUD data sampah
- verifikasi transaksi
- update data anggota
- konversi sampah ke uang
- melihat analytics
- melihat log aktivitas
- approve pencairan

ANGGOTA:

- setor sampah
- melihat saldo
- melihat histori transaksi
- upload foto sampah
- pencairan saldo 3 bulan sekali

==================================================
DATABASE ENTITIES

Buat Prisma schema modular untuk:

- User
- Sampah
- Transaksi
- Tabungan
- Pencairan
- Logs

Tambahkan:

- enum role
- enum transaction status
- timestamps
- relasi lengkap
